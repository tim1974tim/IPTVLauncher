# IPTV Launcher — проект для Tanix W2 / SlimBOX 11.46

Стартовый Android TV проект для приставки Tanix W2 (4/32 ГБ) с Android 11. Целевая версия приложения — API 30. Интерфейс тёмный; предусмотрены загрузка M3U/M3U8 по URL или из файла, разбор `group-title`, `tvg-logo`, `tvg-id`, воспроизведение через AndroidX Media3 ExoPlayer, управление DPAD и сохранение последнего канала. Для локального файла сохраняется URI-доступ, чтобы попробовать восстановить плейлист после перезапуска.

## Сборка APK
1. Откройте папку `IPTVLauncher` в Android Studio.
2. Дождитесь Gradle Sync и установки Android SDK Platform 35 (compileSdk).
3. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK появится в `app/build/outputs/apk/debug/`.

В манифесте объявлены категории `LEANBACK_LAUNCHER` и `HOME`. Возможность назначить приложение главным экраном зависит от прошивки SlimBOX и системных настроек устройства.

**Статус:** добавлены создание и восстановление JSON-резервной копии, а также предложение восстановления при первом запуске. Сборка в этой среде и проверка на реальной Tanix W2 ещё не выполнены. Перед повседневным использованием нужно проверить работу с реальным пультом, плейлистами и EPG на приставке.


## Сборка APK через GitHub Actions (без Android Studio)

1. Создайте на GitHub новый репозиторий (можно Private).
2. Распакуйте архив и загрузите **содержимое папки `IPTVLauncher`** в корень репозитория — так, чтобы `app/`, `build.gradle.kts` и `.github/` были на верхнем уровне.
3. Откройте вкладку **Actions** и выберите workflow **Build Android APK**.
4. Нажмите **Run workflow** (если запуск не начался автоматически после загрузки файлов).
5. Дождитесь зелёной отметки успешной сборки. Откройте завершённый запуск и скачайте архив из раздела **Artifacts** — имя будет начинаться с `IPTVLauncher-`.
6. Распакуйте artifact ZIP. Внутри будет APK с номером версии, например `IPTVLauncher-v0.4.23.apk`; перенесите его на Tanix W2 и установите.

Если сборка завершится ошибкой, пришлите сюда текст ошибки или скриншот вкладки Actions. APK пока является отладочной сборкой и не подписан ключом для публикации в магазине.


## Резервное копирование настроек

В меню, открываемом удержанием OK 3 секунды, доступны создание и восстановление полной резервной копии в JSON. Копия включает все поддерживаемые значения SharedPreferences (строки, числа, логические значения и наборы строк), а также локальный кэш M3U-плейлиста (если он есть и не превышает 30 МБ). При первом запуске после заставки можно вручную выбрать JSON-файл, восстановить настройки или пропустить этот шаг. При восстановлении текущие настройки заменяются данными копии.
